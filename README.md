A modern, high-end web application for **Verola Events & Communications** — premier luxury event management, production, and spatial design firm based in Addis Ababa, Ethiopia.

---

## ✨ Features

- 🌓 **Seamless Light & Dark Theme Toggle**: Instant theme switching saved across sessions in `localStorage`.
- 🎭 **Interactive "Stage-Up" Services Slider**: Hover/click focus carousel where cards stage up with rich details and direct inquiry triggers.
- ⏱️ **Animated Stat Rolling Counters**: Smooth cubic ease-in numbers (e.g. `1990 → 2026`).
- 🗺️ **Our 4-Step Process ("How It Works")**: Clear step-by-step breakdown from initial consultation to event execution.
- 📱 **Fully Responsive & Accessible**: Optimized for mobile, tablet, and ultra-wide displays.
- 🎨 **Luxury Brand Design**: Custom Cormorant Garamond display typography, warm brand pastels (`#f7a8c4`, `#ffd97d`), and glassmorphism.

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18 or higher) installed.

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Eyoel1/verola.git
   cd verola
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Build & Production

To build the production bundle:

```bash
npm run build
```

To run the production server locally:

```bash
npm run start
```

---

## 🌐 Deployment

This application is optimized for one-click deployment on **[Vercel](https://vercel.com/)**:

1. Import `Eyoel1/verola` on [Vercel](https://vercel.com/new).
2. Accept default framework settings (**Next.js**).
3. Click **Deploy**.
